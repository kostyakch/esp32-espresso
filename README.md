# Контроллер эспрессо

### Подключение (ESP32 DevKit)
- PT100 + MAX31865 (SPI): CS=GPIO5, MOSI=GPIO23, MISO=GPIO19, CLK=GPIO18, 3V3, GND
- SSR нагрева (RexC-100 SSR-40DA): IN+=GPIO26, IN-=GND, AC нагрузка последовательно с нагревателем
- SSR помпы (SSR-10DA/SSR-25DA): IN+=GPIO27, IN-=GND, AC нагрузка последовательно с помпой
- Кнопка пролива: GPIO33 -> GND (внутренняя подтяжка включена)
- Кнопка режима пара: GPIO32 -> GND (внутренняя подтяжка включена)

### Спецификация подключения по твоим текущим пинам и коду
- PT100 + MAX31865 (SPI)
  - MAX31865 V3V → 3.3V ESP32
  - MAX31865 GND → GND
  - MAX31865 SCK/CLK → GPIO18
  - MAX31865 SDI/MOSI → GPIO23
  - MAX31865 SDO/MISO → GPIO19
  - MAX31865 CS → GPIO5
- PT100 → клеммы RTD на MAX31865 (в коде используется 2‑wire; по diag 2/4‑wire дают верные показания)
  - Подключи два провода датчика к RTD+ и RTD- (или по схеме платы для 2‑wire)
  - Если на плате есть джампер 2/3/4‑wire — поставь 2‑wire. При сомнении отправь в Serial команду `diag`

- SSR для нагрева (RexC‑100 SSR‑40DA)
  - Вход SSR+ → GPIO26
  - Вход SSR− → GND
  - Выход SSR → последовательно в разрыв фазного провода нагревателя (AC)

- SSR для помпы (SSR‑10DA / SSR‑25DA)
  - Вход SSR+ → GPIO27
  - Вход SSR− → GND
  - Выход SSR → последовательно в разрыв фазного провода помпы (AC)
  - Используй один SSR; если помпа AC, бери SSR‑25DA (с запасом по току). Если помпа DC — нужен DC‑SSR, а не AC.

- Кнопка пролива (GPIO33)
  - Один контакт → GPIO33
  - Второй контакт → GND

- Кнопка режима пара (GPIO32)
  - Один контакт → GPIO32
  - Второй контакт → GND
